Privacy Policy

Anti-Lag Shield Pro • Last Updated: November 1, 2026 • Developer: NightKnight24
Summary: Anti-Lag Shield Pro is 100% on-device software. We collect zero personal data, zero analytics, zero telemetry, and zero browsing activity.

1. Zero Data Collection Architecture

Anti-Lag Shield Pro operates with root/elevated system privileges on iOS and iPadOS. We adhere to a strict zero-telemetry policy: no personal data is collected, monitored, or transmitted under any circumstances.

2. Local On-Device Processing

  • Network Gateway Locking: Optional custom router IP and MAC overrides are stored exclusively on-device in /var/mobile/Library/Preferences/com.nightknight.antilagshield.plist to bind Darwin's kernel ARP cache. No network identifiers are ever sent off your device.
  • Latency Telemetry: Ping latency tests to 1.1.1.1 and your gateway measure round-trip packet response times locally on demand.
  • Flash Storage Cleaner: Purges stale crash dumps (.ips) and WebKit temp files directly on local NAND flash. No files or personal documents are accessed or uploaded.
  • Turbo UI: Adjusts Darwin accessibility preferences locally to bypass GPU blur shaders.

3. Third-Party Services & Trackers

This software contains no advertising SDKs, no analytic trackers (such as Google Analytics or Firebase), and no cookies.

4. Open Source Auditing

Anti-Lag Shield Pro is open-source. All code and scripts may be audited on GitHub at: github.com/NightKnight24/AntiLagShield.

5. Contact

For questions or security concerns, visit the project repository issues page: github.com/NightKnight24/AntiLagShield/issues.
